# 双后端架构方案：Go 优化 + CF Workers 新建

## 核心原则
- **保留不删除**：已写好的 PostgreSQL/Redis/密码登录等服务代码全部保留
- **开关与降级**：通过环境变量/特性开关控制功能启停，不可用时自动降级
- **API 契约一致**：CF Workers 后端与 Go 后端实现完全相同的 API 路径、请求/响应格式

---

## 方案 A：Go 后端 2C2G 优化

### A1. 数据库双驱动支持（SQLite + PostgreSQL）
- 通过 `DB_DRIVER=postgres|sqlite` 环境变量切换
- 修改文件：
  - `backend/internal/config/config.go` — 根据 DB_DRIVER 初始化不同驱动
  - `backend/internal/model/models.go` — Tags 等 `text[]` 字段增加 SQLite 兼容的 JSON 序列化/反序列化
  - `backend/internal/service/post.go`、`project.go`、`ai_news.go`、`ai_tool.go` — 数组字段读写适配
  - `backend/Makefile` — 新增 SQLite 编译目标（需 CGO_ENABLED=1）
- SQLite 模式：WAL 模式、`SetMaxOpenConns(1)`、单文件数据库
- PostgreSQL 模式：保持现有逻辑不变，收紧连接池 `MaxOpenConns(10)`

### A2. 缓存双模式支持（内存 + Redis）
- 通过 `CACHE_DRIVER=memory|redis` 环境变量切换
- 修改文件：
  - `backend/internal/utils/cache.go` — 增加 `sync.Map` 内存缓存实现，接口与 Redis 版一致
  - `backend/internal/middleware/auth.go` — Token 黑名单：Redis 可用走 Redis，否则走内存 `sync.Map` + TTL 清理
  - `backend/internal/middleware/auth_limiter.go` — 限流计数器：同理双模式
  - `backend/internal/utils/token_revocation.go` — Stamp 管理：Redis 可用走 Redis，否则走内存
- Redis 连接失败时自动降级为内存模式（不 Fatal）

### A3. 移除空转功能（减少资源占用）
- 移除 Prometheus 中间件挂载（代码保留，不挂载到路由）
  - `backend/cmd/server/main.go` — 注释/条件跳过 `MetricsMiddleware()` 和 `/metrics` 路由
- 移除 WebSocket Hub 挂载（前端无 WebSocket 调用）
  - `backend/cmd/server/main.go` — 条件跳过 `/ws` 和 `/online` 路由
- 收益：减少 `prometheus/client_golang`、`gorilla/websocket` 编译体积和运行时内存

### A4. 编译与部署优化
- `backend/Makefile` — 新增目标：
  - `build-slim`：`go build -ldflags="-s -w"` 去除调试信息
  - `build-sqlite`：`CGO_ENABLED=1 go build -tags sqlite` 内嵌 SQLite
- `backend/Dockerfile` — 多阶段构建优化，最终镜像精简
- 新增 `backend/docker-compose.slim.yml` — 单容器部署（无独立 PG/Redis）
- 确保 `GIN_MODE=release`

### A5. 定时任务优化
- `backend/cmd/server/main.go` — 定时发布和清理任务通过环境变量控制是否启用
- 可选通过管理后台手动触发（已有 API）

## 方案 B：CF Workers 后端新建

### B1. 项目初始化与基础设施
- 新建 `cf-worker/` 目录
- 文件：
  - `cf-worker/package.json` — 依赖：hono, drizzle-orm, @hono/zod-validator, zod, jose
  - `cf-worker/wrangler.toml` — D1/KV/R2/Cron 绑定 + 环境变量
  - `cf-worker/tsconfig.json`
  - `cf-worker/src/index.ts` — Hono 入口
  - `cf-worker/src/env.d.ts` — Env 绑定类型定义

### B2. 数据库 Schema（Drizzle + D1）
- 文件：`cf-worker/src/db/schema.ts`
- 19 张表 Drizzle 定义，关键适配：
  - UUID → `text` + `crypto.randomUUID()`
  - `text[]` → `text` 存 JSON 字符串
  - `timestamp` → `text` ISO 8601
  - `boolean` → `integer` (0/1)
- 迁移 SQL：`cf-worker/drizzle/001_initial.sql`
- 种子数据：`cf-worker/src/db/seed.ts`（默认管理员）

### B3. 中间件层
- `cf-worker/src/middleware/cors.ts` — CORS（对齐 Go 版）
- `cf-worker/src/middleware/auth.ts` — JWT 验证（jose）+ KV 黑名单 + Stamp 检查
- `cf-worker/src/middleware/rate-limit.ts` — KV 计数器限流
- `cf-worker/src/middleware/security.ts` — 安全头 + CSP
- `cf-worker/src/middleware/role.ts` — 角色权限检查

### B4. 认证系统（带降级策略）
- 文件：
  - `cf-worker/src/routes/auth.ts`
  - `cf-worker/src/services/auth.service.ts`
  - `cf-worker/src/utils/jwt.ts`
  - `cf-worker/src/utils/password.ts`
- JWT 双令牌：access(24h) + refresh(7d)，用 `jose` 库
- Token 黑名单：KV 命名空间，TTL = token 剩余有效期
- 安全 Stamp：JWT payload 嵌入
- **密码哈希降级策略**：
  - 环境变量 `AUTH_MODE=full|oauth-only`
  - `full` 模式：尝试 Argon2id WASM，若 CPU 超限自动降级
  - `oauth-only` 模式：禁用密码登录/注册入口，仅开放 OAuth
  - 前端通过 `GET /api/v1/auth/registration-open` 响应判断是否展示密码登录表单
- 端点完全对齐 Go 版

### B5. OAuth 系统
- 文件：`cf-worker/src/services/oauth.service.ts`
- Google + GitHub OAuth，`fetch()` 交换 code → token → userinfo
- 三级匹配逻辑与 Go 版一致（oauth 精确匹配 → email 匹配 → 新建用户）

### B6. 公开 CRUD 路由（批量实现）
- 文件：
  - `cf-worker/src/routes/posts.ts`
  - `cf-worker/src/routes/projects.ts`
  - `cf-worker/src/routes/categories.ts`
  - `cf-worker/src/routes/tags.ts`
  - `cf-worker/src/routes/friend-links.ts`
  - `cf-worker/src/routes/ai-news.ts`
  - `cf-worker/src/routes/ai-tools.ts`
- 分页统一格式：`{ data, total, page, page_size, total_pages }`
- 数组字段 JSON 序列化/反序列化
- 浏览计数：KV 原子递增 + 定期批量回写 D1（节省 D1 写入配额）

### B7. 评论系统
- 文件：
  - `cf-worker/src/routes/comments.ts`
  - `cf-worker/src/services/comment.service.ts`
- 敏感词过滤：D1 加载 → 内存正则匹配
- 信任分级：`comment_approved_count >= 3` 自动通过
- Turnstile 验证：`fetch` CF Turnstile API
- IP 归属地：`request.cf.country` / `request.cf.city`（CF 内置，替代 ip2region）
- XSS 清洗：使用 DOMPurify 或简单文本清洗

### B8. 文件上传（R2）
- 文件：`cf-worker/src/routes/media.ts`
- R2 绑定 `MEDIA_BUCKET`
- multipart 接收 → MIME 校验 + magic bytes → 存 R2 → 元数据写 D1
- 大小限制、扩展名白名单与 Go 版一致

### B9. 管理后台路由
- 文件：`cf-worker/src/routes/admin.ts`
- 用户管理、评论审核、敏感词 CRUD、风控日志、站点设置、统计
- 审计日志写入 D1

### B10. 分析模块
- 文件：`cf-worker/src/routes/analytics.ts`
- 事件记录写入 D1 `analytics_events` 表
- 统计查询：KV 缓存预计算结果（节省 D1 读取配额）

### B11. 验证码方案
- 文件：`cf-worker/src/routes/captcha.ts`
- 仅保留 Turnstile（CF 原生生态）
- 图形验证码端点返回 404 或重定向到 Turnstile
- 前端 `CaptchaService` 检测 `turnstileSiteKey` 有值则自动切换

### B12. Cron Triggers（定时任务）
- 文件：
  - `cf-worker/src/cron/scheduled-publish.ts` — 每分钟定时发布
  - `cf-worker/src/cron/cleanup-users.ts` — 每日清理未验证用户
  - `cf-worker/src/cron/sync-ai-news.ts` — 移植 `scripts/sync-ai-frontline.mjs`
  - `cf-worker/src/cron/sync-lab-tools.ts` — 移植 `scripts/sync-lab-resources.mjs`
  - `cf-worker/src/cron/sync-github-projects.ts` — 移植 `scripts/sync-github-projects.mjs`
  - `cf-worker/src/cron/daily-stats.ts` — 移植 `scripts/generate-daily-stats.mjs`
- wrangler.toml crons 配置
- 使用 `ctx.waitUntil()` 处理长时间任务

### B13. RSS/Feed 动态生成
- 文件：`cf-worker/src/routes/feed.ts`
- `GET /feed` — 从 D1 查询最新文章，动态生成 RSS 2.0 XML
- KV 缓存 1 小时，文章发布时主动失效缓存
- 支持按分类/标签过滤
- 兼容现有 `feed.xml` 格式

### B14. 部署配置
- `cf-worker/wrangler.toml` 完整配置
- D1/KV/R2 资源创建命令
- 环境变量/Secrets 清单
- `cf-worker/README.md` — 部署指南

## 域名方案建议

| 方案 | 费用 | 说明 |
|------|------|------|
| CF Workers 默认域名 | 免费 | `xxx.workers.dev`，功能完整但不够专业 |
| Cloudflare 注册新域名 | ~$10/年 (.com) | 配合 CF 使用体验最佳 |
| GitHub 提供 .github.io | 免费 | 仅前端，后端需另配 |
| 免费域名 (eu.org 等) | 免费 | 申请周期长，但可用 |

**推荐**：先用 `xxx.workers.dev` 开发测试，正式上线前注册一个便宜域名绑定到 CF。

## 风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| CF 免费 10ms CPU 限制导致密码哈希不可用 | 密码登录/注册失败 | AUTH_MODE=oauth-only 降级，保留代码但关闭入口 |
| D1 免费 500 万行读取/天 | 高流量时超限 | KV 缓存热点数据、浏览计数批量写入、分页限制 page_size≤50 |
| KV 免费 1000 写入/天 | 限流/黑名单写入超限 | Token 黑名单用 TTL 自动过期减少写入、限流用滑动窗口减少计数更新 |
| SQLite 不支持并发写入 | Go 后端高并发写入失败 | 2C2G 个人博客场景流量极低，WAL 模式提升并发读性能 |
| text[] 字段 SQLite 不兼容 | 标签等字段读写异常 | 统一 JSON 字符串存储，封装 JSONArray 工具类型 |
| OAuth 回调地址变更 | OAuth 登录失败 | 在 Google/GitHub 控制台注册 CF Worker 域名为新回调 URL |
| CF Cron 执行时长不足（HTML 爬取） | 内容同步不完整 | waitUntil() 延长、分批处理 |
